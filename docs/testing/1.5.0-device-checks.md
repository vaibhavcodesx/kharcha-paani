# Kharcha Paani 1.5.0: what to check on your phone

1.5.0 is everything since 1.4.0: ask-to-pay and the October audit fixes (#54–#60), plus the
sixteen PRs that were waiting for a device test (#61–#70, #72–#77). The full list is in
CHANGELOG.md under 1.5.0.

**Where to get it:** GitHub → Releases → "Kharcha Paani v1.5.0" → `KharchaPaani-v1.5.0.apk`.
Install it **over 1.4.0, without uninstalling**: the first check is that nothing you already have
is lost.

Tick each box, and for anything that doesn't behave as described, note the number and what you saw
(a screenshot helps). Send the list back in one message; nothing here needs to be done in one sitting.

Items marked **(important)** are the ones a broken build would show first. Do those before the rest.

## 0. Install and first open (important)

- [ ] 0.1 Install over 1.4.0. The app opens on Home with all your entries, friends, groups and
      balances as they were. (The phone's database moves from version 8 to 10 here: ask-to-pay's
      log, then bill photos.)
- [ ] 0.2 Settings → Apps → Kharcha Paani → About shows version 1.5.0.
- [ ] 0.3 Sign out and sign back in with Google. It works, and your data comes back. (#75, #77)
- [ ] 0.4 Add an expense, wait a minute, and check it on another phone or after reinstalling: it
      synced.

## 1. Opening the app offline (#77, important)

- [ ] 1.1 Open the app, then put the phone in airplane mode and wait an hour (or move the clock 1 h
      forward).
- [ ] 1.2 Force-stop the app and open it. It opens on Home within about 1.5 s (before this fix it
      stayed blank).
- [ ] 1.3 Open the account sheet: it says Offline.
- [ ] 1.4 Turn the network back on: the profile loads by itself, and nothing you added offline is lost.

## 2. Widgets, notifications and sharing into the app (#74)

Open the app once after updating, so old widgets refresh.

- [ ] 2.1 Widget **Add** opens the add sheet.
- [ ] 2.2 Widget mic starts voice entry and fills the sheet.
- [ ] 2.3 Widget **Splits** opens Splits.
- [ ] 2.4 The 9 PM daily reminder opens the add sheet.
- [ ] 2.5 A "payment to confirm" notification opens the answer sheet.
- [ ] 2.6 Share a screenshot, a PDF and an SMS into the app: each one still opens the right sheet.

## 3. Switching accounts (#75)

- [ ] 3.1 Get a "payment to confirm" notification, then sign out: the notification disappears.
- [ ] 3.2 Export a CSV, sign out, sign in as another Google account: nothing from the first account
      shows. (The old export file is deleted too; you can't see that without adb, so skip it if you
      like.)

## 4. Bill photos (#76, new)

- [ ] 4.1 Add an expense → Bill photo → Take photo → shoot a receipt: the thumbnail appears. Save.
      The feed row shows a receipt icon.
- [ ] 4.2 Open it again → tap the thumbnail → zoom in → Choose another → Save.
- [ ] 4.3 Scan bill from Home: the sheet opens with that bill already attached.
- [ ] 4.4 Share a screenshot into the app: same.
- [ ] 4.5 Delete the expense → Undo: the photo is still there. Delete again and let the snackbar
      go: the photo goes.
- [ ] 4.6 Add a photo, then close the sheet without saving: it asks "Discard?".

## 5. Backups (#61, #73)

- [ ] 5.1 Settings → Restore from a backup → pick a file: a dialog shows the backup's date and what
      it holds. **Cancel** → nothing changes.
- [ ] 5.2 Same again, then **Restore** → "Restored N items".
- [ ] 5.3 (Optional, longer) Add friends A and B, add an expense A paid split three ways, delete A,
      export a backup, restore it on a fresh install: B's balance is the same as before.

## 6. Smaller fixes

- [ ] 6.1 Back button (#70): open Insights, press Back → Home. Press Back again → the app closes.
      With a sheet open on Splits, Back closes the sheet first.
- [ ] 6.2 Voice entry and the microphone (#64): voice entry still works (it uses Google's speech
      screen). Settings → Apps → Kharcha Paani → Permissions no longer lists Microphone.
- [ ] 6.3 Statement import (#72): import a statement that includes your salary. That row shows
      unticked with "Much bigger than the rest", and ticking it adds it.
- [ ] 6.4 Subscriptions (#66): add a subscription that started last month, open the app, then set the
      phone's time zone to New York and reopen: no second charge for this month appears. Set the
      zone back afterwards.
- [ ] 6.5 Month change (#63, optional): with Home open, change the phone's date to the 1st of next
      month. Home moves to the new month within a minute. Set the date back afterwards.

## 7. Ask a friend to pay you back (#54, new since 1.4.0)

- [ ] 7.1 Open a friend who owes you → Settle → on the "{Friend} paid you" side, tap "Ask {name} to
      pay". The preview lists each expense since you were last square, the total matches their
      balance, and your UPI ID is there.
- [ ] 7.2 Change the amount first (say half): the message says "Asking ₹X of the ₹Y".
- [ ] 7.3 Share it to WhatsApp and send it to yourself or a test chat: the text reads casual and
      friendly, and the payment-code picture is attached. Does it feel like something you'd happily
      send? (Tell me if any line sounds formal or awkward.)
- [ ] 7.4 Back in the app, the friend's row says "Owes you · Asked just now". Closing the share
      sheet without picking an app does **not** mark it as asked.

## 8. Fixes from the October audit (#55–#60)

- [ ] 8.1 Switch an expense with a split to Income and save: no friend shows as owing you for it.
- [ ] 8.2 Delete an entry, then sign out while "Undo" is still showing: no crash.
- [ ] 8.3 Share a very large photo (a full-resolution camera shot) into the app: it opens the sheet
      without freezing.
- [ ] 8.4 With a friend who isn't on the app, split something by percentage (33.3% each between
      three): the shares add up to the total.

## 9. Things you can't see (no check needed)

- #62: a split from another phone that arrives before its expense is no longer skipped. It's a race
  between two phones, so it's covered by tests only.
- #65, #67, #69: CI now lints and builds the release variant on every PR, there's a release
  checklist (`docs/release-checklist.md`), and a launch test opens every tab.
- #68: the app now runs on Android 7. Only relevant if you have an Android 7 phone to try.

## Not in 1.5.0

- **#71 (R8 shrinking)** is held back. If shrinking broke sign-in, you'd have nothing to test. It
  comes in a separate build with its own short check.
