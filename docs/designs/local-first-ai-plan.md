# AI choice implementation plan

Goal: the device-wide Use AI switch reliably blocks Gemini and external speech when off, while local entry still works. Spec: [local-first.md](local-first.md).

1. Add real-Room `AiDisabledTest` against existing entry APIs, seeding `ai_settings/enabled=false`, previously accepted disclosure and a counting HTTP boundary. Text, bill, PDF, Insights and trip routes must make zero requests; local saves and photo attachment must remain correct. Commit tests first, open draft PR, inspect the predicted red CI before product edits.
2. Add `AiSettings` with synchronous persisted read, observable preference updates and durable write. It is separate from disclosure consent and defaults enabled for existing installs. SharedPreferences is deliberate: request gates must be available before asynchronous DataStore collection, including on cold launch.
3. Add `GeminiRepository.setAiEnabled(Boolean)` plus an injected policy predicate. Track only this repository's HTTP Calls under a lock; check policy before registering, cancel tracked calls on disable, and recheck policy/coroutine cancellation after each response and before fallback. Cover both text/receipt/answer `callModel` and separate PDF execution.
4. MainViewModel exposes reactive `aiEnabled`; every dispatch checks the persisted policy separately from `aiAvailable` build capability. Off uses existing local/manual alternatives and clear resource messages. Disable cancels text/receipt/statement/Insights/trip jobs, clears loading and pending notice callbacks, and refuses stale notice acceptance. Receipt job ownership joins the existing cancellation path. No consent is silently granted on enable.
5. AccountSheet adds the existing switch-row pattern; MainActivity binds it. CaptureCard and HomeScreen receive the reactive preference, label AI actions and refuse both microphone and widget speech while off; ordinary analytics remain available and AI question controls follow enabled state. Also show a Gemini-use notice at each accepted AI action, without changing the owner's disclosure wording.
6. Add setting-toggle/recreation, pending-notice, in-flight/fallback transport and capture semantics tests; retain all existing AI consent tests. Independently review all diffs, add one Unreleased entry and solo-log row. Exact-head CI must pass unit-tests/lint/release-bundle against latest main before squash merge. Local Gradle is skipped below4GB free RAM; no emulator. Guest session and full backup are later separate PRs, not implied delivered by this change.

Phone checks: switch off with consent previously accepted; try Quick Add, bill photo, statement, Insights, trip and widget Speak; restart and confirm off persists; save an entry manually with a photo; turn on and verify disclosure is still required if never accepted; switch off during a slow read and confirm no late draft change.
